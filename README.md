# Education Apps — CPNS Exam Practice

A Java desktop application (Swing) for practicing the Indonesian civil servant (CPNS) basic competency test.

## Features

- **Login** screen
- Three practice sections matching the CPNS test:
  - **TWK** — Tes Wawasan Kebangsaan (national insight)
  - **TIU** — Tes Intelegensia Umum (general intelligence: synonyms, antonyms, etc.)
  - **TKP** — Tes Karakteristik Pribadi (personal characteristics)
- Result feedback after answering
- **Advice** form, **Help**, and **About** pages

## Run

A pre-built JAR is included:

```bash
java -jar dist/EducationalApps.jar
```

Or open the project in **NetBeans** (it is a NetBeans Ant project) and run it from there.

## Tech

Java 8, Swing (NetBeans GUI Builder), AbsoluteLayout.
